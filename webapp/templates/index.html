Phishing URL Checker

Paste a URL. This is a demo model trained on real phishing + legitimate URL data — no page is fetched, only the URL string is analysed.

Demo model only, built from lexical URL features (length, tokens, entropy, brand names, look-alike spellings, etc.) — no network lookups. Three possible answers, not two: it will return UNCERTAIN rather than guess when the URL text genuinely does not contain enough evidence — for link shorteners, whose destination is not derivable from the URL at all, or when the score falls inside a calibrated uncertainty band measured on held-out data. It is still not perfectly accurate: telling a well-known brand's real domain from a look-alike is a genuinely hard problem. That trade-off, and knowing when to abstain instead of bluffing, is itself one of the things this project studies.

Feature-Provenance Lookup (C3)

This is a separate tool, not used by the checker above. It performs one real WHOIS lookup, one real DNS resolution, and one real TLS handshake against any domain you enter, so you can see the C3 audit's underlying lookups actually happen — live, not from a saved CSV. This project's own finding was that these lookup-based ("P2") features do not improve detection over lexical features alone, which is why the checker above never uses them.
